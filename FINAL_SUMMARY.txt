================================================================================
DATA FLOW
================================================================================

1. Freelancer clicks "Ambil Project" button
2. handleTakeProject function called with jobId
3. PATCH request sent to /api/jobs/{jobId}
4. Body: { action: "take", freelancerId: {user.id} }
5. API validates:
   - Freelancer ID exists
   - Job exists
   - Job status is "open"
6. Database executes:
   UPDATE jobs SET status='in_progress', freelancerId=?, updatedAt=NOW()
7. Response returns updated job
8. UI updates local state
9. Modal closes
10. Success message displayed
11. Project list refreshes
